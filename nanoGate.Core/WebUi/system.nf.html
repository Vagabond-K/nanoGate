Backup and restore

Exports or restores the communication settings and saved point mappings as a JSON file. Wi-Fi and IP settings are not included.

Maintenance

Restore defaults resets only the communication settings and keeps point mappings and network settings. Factory reset erases everything and starts in setup AP mode.

Loading...

Device BOOT button: after booting, press and hold it for 3+ seconds to enter setup mode (AP), or 10+ seconds to factory reset. In setup mode, a short press returns to the saved Wi-Fi. On boards with a status LED it lights while held, blinks after 3 seconds, and blinks fast after 10 seconds. Note that holding it during power-on or reset enters firmware download mode.

The gateway protocols provide no authentication or encryption. The management page can require login with admin access control (password / API key), but communication itself is plain HTTP - use it only on a trusted, isolated network.
